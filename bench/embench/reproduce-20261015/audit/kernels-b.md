# Kernels B audit against KERNEL-POLICY.md ("same algorithm only")

Scope: every old-backend kernel written or rewritten by kernels agent B in rounds 1-3.
Round 1 = branch claude/cosci-kernels-b-20261015 up to f67c2da0; round 2 = same branch up to b019d668;
round 3 = branch claude/cosci-kernels-b-r3-20261015 (39f978af .. d105d8d3; patch A merged in m99, patch B in m100,
patch C on hold). Gains are the A/B cycle ratios recorded when each kernel landed (workload, vs the previous commit).
Strict reading: anything that skips source reads/steps, builds a structure the source does not build, or derives
charges/state by formula instead of executing the iterations is marked substitution; "unsure" is used only where the
work is all performed but in a representation the policy does not name.

Summary: substitution = xs, qk, ls, hs, tv, tb, st, hd, eb, qa (10); unsure = bp, mr, lcg, qq (4); same-algorithm =
k1-sha, sha-crypto (pending the separate crypto policy), zf, pz, mmx, tbat, ip, ci, wo, lr, rls, rs, ab, ns, ek, ik, pb,
hpa, hpd, lp (20). Not a kernel: 39f978af (keep markers only).
