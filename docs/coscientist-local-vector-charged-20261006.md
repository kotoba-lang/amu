## What was implemented and proved

The [uncharged-only predecessor](coscientist-local-vector-write-20261006.md)
admitted zero original writers because statemate put has an entry fuel charge.
This separately registered successor accepts an exact closed typed natural
Vec/I64/I64→Vec wrapper with an optional single leading FUEL and module-unique
owned label; all instruction operands, reserved fields and function metadata
must match. Existing mode2 low-local/depth bounds reserve x3/x4 for descriptor
length/item base. The original first read still validates its handle and index.
A same-local unchanged witness can omit a repeated handle/descriptor lookup on
a writer; its own unsigned bounds check and trap remain.

The original published five-word fuel sequence is byte-identical before each
shortened write. It uses x16/context memory and does not clobber x3/x4. Insufficient
fuel traps before the write with the same partial state. Unknown/open calls,
branches/labels, root replacement and coalesced writes remain witness barriers.
No arbitrary standalone FUEL is allowed to preserve the witness. This does not
memoize computation results or connect a native DefCID cache.

Four native self-build generations are byte-identical:837496 bytes, SHA256
`05760d3c5eb610e3fb3988e8f2cffc2b09ebc28af731162ed9f1bbbc7bf1167b`.
6,300 independent full-state oracles exercise aliasing, root replacement, signed
extremes, zero values, invalid indices, division traps, fuel exhaustion and all
allocated items.209 original19 partial-fuel states,38 original resource states
and72 new resource/partial-item states match, totaling6,619 supervisor comparisons.
35 instruction-field,11 metadata/call and7 mode mutations, plus open/duplicate/
invalid-callee guards, are refused. The existing508 fixtures and14,523 native
executions pass; their generated blob and unit golden remain byte-identical.

Independent actual SIR/emission snapshots cover all19 original functions and
contiguous instruction regions. Original SIR, frames, local/depth/leaf metadata
and fuel events match the product.18 guest images are byte-identical. statemate
21316→21239 words comes from exactly7 writers saving11 words each, while keeping
all5 charge words.119 captured reads are static counts, not dynamic time shares.

No product source, permanent fixture or golden is changed. Product gates and
committed-source integrated adoption are not run because the performance
prerequisite failed. No merge, release, default rung/bin change or100% claim.

## Next falsifiable hypothesis

Read-only dynamic path counts should establish whether repeated same-handle
terminal-chain transitions dominate the remaining cost. A diagnostic guest must
be kept separate from unchanged performance arms; its instrumentation overhead is
not a speed measurement. Only after useful transitions are demonstrated should
a separately sealed internal entry ABI be considered for descriptor transfer.
Public entries must remain cold; every target, scratch register, invalidation,
allocation/effect and partial fuel/trap path needs proof. Cross-terminal reuse is
unimplemented and is not inferred safe from this local witness proof.

Definition identities content-address checked normalized typed KIR plus profile,
effects, interfaces and dependencies. Computation recipes can also be content
addressed, but a result key additionally needs inputs, state, effects and resource
semantics. Reusing verified compiler analysis/artifacts is a separate opportunity;
the native DefCID/artifact/result-cache bridge remains unconnected. See the
[identity contract](coscientist-content-address-20261005.md). Unison identifies
code by its contents, as documented in its [official explanation](https://www.unison-lang.org/docs/the-big-idea/).
