## New algorithm and semantic evidence

The prototype scans the entire closed SIR for BR/BRZ/BRNZ references to a label.
Only a module-unique label with no incoming reference and a live fallthrough
predecessor preserves the descriptor witness. Indirect/unknown control transfers
are excluded by the existing closed-mode admission. Incoming branches, duplicate
labels and dead predecessors erase it; explicit/coalesced root writes still
invalidate it. No checked access or trap moves ahead of its original fuel.
This is one-off new control-flow proof authoring, not a mechanical refactor;
product source is untouched and the prototype is archived separately.
