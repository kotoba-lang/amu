# Embench port comparison: r6l, r6m and stage-0

Measured 2026-10-04 at 13:04–13:05 JST over SSH on the Tailscale host
`asher`: Apple M4, 10 cores, 16 GiB RAM, macOS 26.2. The host had been
running for 24 days. All compilers ran on this same host. Stage-0 is the
GraalVM bootstrap reference; r6l and r6m are the native unified images.

Evidence is in `docs/evidence/embench-asher-20261004/`: `raw-results.tgz`
contains all three qualification reports, raw artifacts, command outputs,
samples and the common runner; `measurement-inputs.tgz` contains the exact
port sources, runner source and qualification harness. The pinned upstream
commit is `09c2ed8c3b7008c95d08b038de4a3f6dc103ed70`. Image identities:

- r6l: `994fb5edd934ef367a7296883bd63ddbdec0c817f092cd2b1daf894830ffb79e`
- r6m: `abcc1318957af7d3a09cfd66c06d17821b5cf47f4c47d02b5620e9e92a24f02e`
- stage-0: `d2cb84f6e7934a638ae928342e13e96a34d13aa66a3f0170fb91cabf3c5e68e2`

Use `scripts/seed/image/compare-embench.sh` with the frozen snapshot for
measurement and `compare-embench-report.mjs` to validate the recovered
evidence and generate tables. Both are bootstrap measurement tools.

One common runner (a1b8778cf9af255f66bba3e3cad20e3baadd9653e18defe429bfa179840665ac); five samples per command and export. Every sampled host load <= 1.40 (limit 4). All 19 correctness exports returned 1.

Compiler timings include process startup. Execution measures one correctness export call, with no warmup. Nine workloads are full correctness translations; ten are adapted probes. These are local port comparisons, not official Embench scores.

r6l and r6m generated byte-identical raw code for 19/19 workloads. Timing differences between identical outputs do not establish a generated-code improvement.
