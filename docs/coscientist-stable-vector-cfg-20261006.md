## Rule and meaning

This successor follows the separately preregistered [negative v1 experiment](coscientist-stable-vector-loop-20261006.md). Admission requires an already-framed original leaf, exactly one typed Vec among at most five parameters, scalar remaining parameters, closed readonly body, at least two vector reads and a valid backedge. No benchmark/function names enter admission.

A bounded local CFG query proves each vector read's handle and every write of the chosen vector local. Every predecessor path must end at a last temporary definition that reads that same chosen local. Other definitions, undefined entries, uncut cycles, malformed labels/edges, unknown effects, calls/capabilities/allocation/writes, or budget exhaustion refuse optimization. Self-tail-loop assignments are checked by the same proof. This establishes a stable-handle induction, not a prior-validation fact.

The candidate reserves three new callee registers for length, items base and runtime validation flag, saves/restores them, and recomputes frame/home placement. The flag starts false. Original first handle validation remains at its original read site after its charge; every read retains an explicit flag guard, unsigned bounds/trap and fresh element load. For materialized temporaries after joins, emission uses the whole-body proven chosen local only in admitted mode3, while preserving original handle/index/destination loading. There is no result memoization, speculative validation motion or compile-time flag elimination.

Scratch is a separate compiler vector of `8+8*(N+1)` words, allocated only after cheap shape/frame guards. Local graph edges are bounded by2N; iterative DFS state byN; body scan by8192. Each rooted query costs O(N+E), with potentially O(N²) queries collectively, and a shared131072-visit budget forces generic fallback. Duplicate-label checks and existing compiler scans have separate costs; this is not a general constant-time matcher. Compiler scratch allocation consumes compilation resources; guest fuel/arena proof is not compiler-budget or OS-stack-limit equivalence.

Definition content identity remains separate from rule/generator/ABI/target recipe provenance. Cacheable computations would require arguments and all observable state. No CID grants authority, no capability/result cache is added, and no general TLC/TLAPS/compiler theorem is claimed.
