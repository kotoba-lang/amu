# Historical ANV instrument sources

These plain-text snapshots preserve the exact sources used by the two recorded
2026-10-27 INSTRUMENT-channel sessions at commit
`49f16bc8ee73a097dd76ab1673915f20c5566410`. The manifest maps each original
`scripts/` path to its snapshot, byte length and SHA-256 digest. Protocols,
logs and publications retain their original provenance.

The recorded route used KBB/CLJK emission, GCC/Vulkan runners and
glslangValidator. These sources are historical evidence outside the adopted
native compiler and executable tool closure. GPU source emission, provider
integration and Amu selfhost qualification remain open. The two session
`analysis.py` files reproduce publications directly from the fixed logs.
