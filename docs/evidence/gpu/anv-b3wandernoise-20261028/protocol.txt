1. UNIT AND STATISTIC (the s35/s36-frozen constructions, UNCHANGED)

- block = 3 consecutive runs of one arm in one window (runs 1-3 = A,
  4-6 = B, ... 34-36 = L).
- block value for one ok cell = pooled median of gpu_ticks over the
  block's 75 samples (25 rounds x 3 runs).
- block-min = min over the 18 ok cells of the block value
  (min-over-18-medians-of-75, exactly the s34-s39 block-min).
- X = the 12 hi block-min values; Y = the 12 tw block-min values.

OBSERVED STATISTIC (frozen): T = RANGE = max - min over the 12
block-min values of one arm at one window (the "wander band" width
that sessions 34/36/38/39 quoted descriptively).

------------------------------------------------------------------
2. NULL AND RESAMPLING (frozen)

H0 (named "run-exchangeable sampling noise"): the 36 runs of one arm
within one window are exchangeable across blocks -- any block
structure in the block-min wander is what re-partitioning the same
window's runs produces from the same window's samples. This null
includes ALL within-run and run-to-run process noise (each run is a
fresh process); it is NOT limited to estimator noise.

Resampling (frozen):
- rng = random.Random(20261028), instantiated ONCE per script run and
  consumed in the frozen probe order:
    (1) s39 hi  (2) s39 tw  (3) s36 hi  (4) s36 tw  (5) s38 hi
    (6) s38 tw
- per trial: perm = list(range(36)); rng.shuffle(perm); split into 12
  consecutive triples; each triple is a pseudo-block; recompute each
  pseudo-block's block-min with the IDENTICAL construction of section
  1; T* = max - min over the 12 pseudo-block-mins.
- TRIALS = 20,000 per probe (pure-Python cost, NAMED -- not the
  s35-frozen 100,000 of the Spearman permutation; p resolution
  1/20,001 ~= 5e-5, far finer than the 0.05 letter threshold).
- p = (1 + count(T* >= T_obs)) / (1 + 20,000), one-sided.

5. NAMED, NOT HIDDEN (frozen caveats)

(a) does NOT prove "estimator noise is the mechanism": the null is

    driver that acts uniformly within the window (or slower than the
    window) is INVISIBLE to this probe and would read (a). (a) means
    "no block-timescale structure beyond run-repartition noise",
    nothing stronger.
(b) would implicate structure at the ~3-run / few-second block
    timescale but NOT name it -- thermal, scheduling, memory state,
    driver state all UNMEASURED; direction UNMEASURED; NO causal

- All three windows are ONE day, ONE host (ANV), ONE instrument; the

  descriptive only (three windows are not a rate).
