     AT FIXED DISPATCH COUNT B=2 AND CONSTANT GRID (the archived
     n = 1,000,003, groups = ceil(n/W) -- WORK_MUL=1 everywhere), IS
     THE CAPTURE REACHABLE BY FAT PER-WORKGROUP WORK -- or does the
     capture stay out of reach at B=2 no matter how much work one
     workgroup carries?

   knob: the new compile-time ITERMUL knob, baked into DERIVED SHADER
   SOURCES (the instrument is untouched -- see section 1): the reduce
   body re-runs ITERMUL times per workgroup (each iteration recomputes
   the same reduction from the same x[]; the parts[] write is inside
   the loop, idempotent; the final stored value is bit-identical to the
   archived value at any ITERMUL, re-checked inside every run by the
   instrument's VERIFY step). The grid is EXACTLY the archived grid at
   every I (n = 1,000,003, WORK_MUL=1): one unit of work = one dispatch
   of the archived grid at ITERMUL=1 cost; an arm (B, I) runs B
   dispatches of the same grid at I-times per-workgroup cost = B*I
   nominal work units. ITERMUL=1 is the archived nominal behaviour.
   Whatever the answer, no mechanism is claimed.
