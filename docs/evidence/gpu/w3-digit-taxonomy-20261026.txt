  (1) The ONLY two arms that answer :parse/malformed are (a) the

  non-digit code point answers :parse/malformed AT ITS OWN STEP, before
  any range verdict. Verdict ok|out-of-range therefore IMPLIES every
  code point is an ASCII digit. (A multibyte code point's first step is
  >= 128 -> non-digit -> malformed at once, so the 1-byte step can never
  walk into a multibyte character.)
