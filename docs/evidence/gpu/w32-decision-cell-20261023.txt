JUN-58 / JUN-55 -- the low band's selection question DECIDED (2026-10-23)

ONE design decision + implementation slice (the slice ADR-0360's low-band
amendment named and left open): whether the narrowing's W = 32 cell should
answer :subgroup-reduce, and how the honesty-lock flip set follows.

DECISION (recorded in ADR-0360, reached code in accelerator_variants):

  W = 32 keeps answering :baseline for ALL THREE OPERATORS on the measured
  device (m1 max fragment + reported subgroup size 32, MSL route). The
  demotion there changes status: it was the fail-safe on unmeasured ground,
  it is now a DECISION on measured ground. The cell's only not-slower signs
  are scoped to the slow clock regime the device sat in while every :sum
  run happened (per-run median gpu-ns 109k -> 36k; no :sum run exists in
  the fast regime), :max's win follows the regime, :min's sign (1.019) is
  NOT ESTABLISHED. A regime-scoped sign is not a selection basis (the
  standard that keeps the LABELED BOOTSTRAP GLSL runs verdict-free), and
  an operator-split answer at one cell off one shape is overfitting. The
  answer keeps the honesty lock (:measured? false, no :measured-cell): no
  cross-regime verdict chose it; the decision did.

  W = 64 and W = 128 JOIN the flip set: their measurement chose the
  demotion (all three operators 1.20-1.25, the penalty band of W >= 256).
  Flipped widths are now W = 64/128/256/512/1024; the :measured-cell
  record's evidence list gains the low-band directory.
