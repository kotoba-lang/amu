     COMMANDS (REAL WORK) INSIDE IT?

   (vkCmdPipelineBarrier with src=TOP_OF_PIPE, dst=BOTTOM_OF_PIPE and

   BATCH dispatches. Empty barriers add bracketed COMMAND COUNT with
   essentially no GPU work. Whatever the answer, no mechanism is
   claimed: a composition that changes the bracket is an OBSERVABLE
   DEPENDENCE, not an explanation.
