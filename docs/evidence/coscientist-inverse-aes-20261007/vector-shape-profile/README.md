# Readonly shape-query profiles: recorded six compiler calls

The archive contains exact content-addressed objects for 107 logical files from the seven profiling source, parser, execution, continuation and review directories listed in its manifest. Sources, diagnostic stdout/stderr, failures, argv/status, native/container outputs, baseline identities and review reports are retained. Cache directories and unrelated workspaces are excluded. The manifest records every original logical path, object SHA-256 and byte size, plus archive SHA-256 and size. Compressed cap is 5 MiB; expanded object cap is 64 MiB.

Copy shape-profile-proof.tgz, shape-profile-proof.manifest.json and verify-shape-profile-proof.py into a fresh folder and run `python3 verify-shape-profile-proof.py`. This offline reader verifies all envelopes and objects, six recorded terminal compiler calls, paired raw query records and their saved accounting tuples. It does not execute bundled code, a native guest, compiler, network, benchmark or solver. Root actual review independently joined every query tuple before packaging. The archive preserves the initial parser failure and the FREC17/LIT5 schema amendment; no native call was retried for that parser correction. Original first four calls plus the continuation's two calls total six. Benchmark bodies and timing are zero.

Pico has 686 queries, six round starts and 449 repeated partial-key occurrences after the first. QR has 1052 queries, ten round starts and 760 repeats. Whole source/KSEED/native/export offset identities match each pinned ordinary baseline. Both final records are work cap 268435456, phase6, refusal1, semantic sites0. These diagnostic outcomes do not qualify cache reuse, optimizer emission, performance, official Embench or C superiority. Stage intervals and final tails are explicitly segmented only where observed. Repeated four-bound keys omit mutable summaries, detail flags, budget/refusal transitions and outgoing accumulation/poison effects; no cache implementation is included.

The root round-propagation audit is included: observed bounds change across rounds (Pico4096, QR2048). Equal accounting per round does not imply equal state or a convergence bug. Worklist scheduling is a future hypothesis requiring separate semantic/effect/poison validation.
