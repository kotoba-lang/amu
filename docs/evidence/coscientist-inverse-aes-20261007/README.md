# AES復号候補の証拠

`inverse-proof.tgz`、`inverse-manifest.json`、`inverse-replay.py` の3ファイルを空のディレクトリにコピーし、`python3 inverse-replay.py` で保存済み証拠を再検査できる。Pythonの標準ライブラリだけを使い、新たなコンパイル・ネイティブ実行・SMT・ネットワーク・測定は行わない。

1,179ファイル、展開前75,060,277 B、圧縮14,264,209 B。アーカイブSHA-256は `a9c245bc505f56b217745148f56623abf6c21d56d7cd175b32e4333fd8001d66`。入力ごとの内容ハッシュ、証明DAGの検査、元19本の生成コード検査と8種類の故意の誤り、4世代の同一性、保存した実機結果4×1,108件と元のテーブル計算、CPU機能・実行前の記録を照合する。親担当も3ファイルだけの新しいディレクトリで成功を確認した。

直接SMTのUNKNOWN、初期の証明記述とその修正、初版の容量検査失敗、ローダーの準備失敗、実機機能の最初の読み取り拒否を保持した。過去のSMT結果はハッシュで照合し、再び解いたとは主張しない。

このパケットは、候補コンパイラの自己再ビルド、静的な生成コード、値保存の証拠、専用命令単体の有限実機検証までを対象とする。実際のコンパイラ生成CALL、燃料・状態の動的検証、製品採用、性能、公式Embenchスコアは含まない。専用命令単体はモード0も復号を実行する。後続の検証をこのパケットから推定しない。
