The current frozen emitter candidate's seal bank is an activation-local, module-owned carrier. Its valid-last publication and immutable consumption provide a lifetime protocol; **they are not a ResultCID, a signature, or a proof that a shared result is correct**. FN/SIR counts and local body/site/creation checks remain useful guards, but are not complete persistent request identity. The source remains frozen and under independent review. A future shared importer must bind the current ComputeCID to the checked ResultCID payload and its verification evidence, then retain every current eligibility/lifetime/ABI/trap check; a matching CID alone never authorizes the three-instruction omission.

V8's existing four-bound key is exact only inside its fixed activation. Mode1 reads a frozen SIR/FREC and graph, phase4 lifetime/effects, phase5 alias/return summaries, parameter mapping and support context; the tuple selects the caller's four entry bounds in that same view. A fresh module or changed context gets a fresh empty memo. Keep this efficient local key rather than computing a global CID for every lookup. It must not become a process-wide map key, and must not be reused for alias mode0 or certificate mode2 without a new request/read-set contract.

A persistent ComputeCID would content-address the canonical calculation request: evaluator and transitive implementation dependencies, query/mode/candidate, strict subject snapshot and dependency/SCC graph, complete ordered read footprint, input/bounds, rules and their direction/phase/termination/cost settings, numeric/ABI/descriptor/trap semantics, and resource/admission/logical-charge contract. DefCID remains separate. Initially use an exact typed/SIR snapshot; name-independent canonicalization and native DefCID bridging are separate unqualified work. Select and test a real canonical encoding and CID codec; a SHA256 hex string is not itself an IPLD CID.

ResultCID would content-address the complete semantic result and replay payload: stable source-edge and target references, parameter ordinal and each aggregated contribution, support, poison and semantic diagnostics, replay preconditions, and any observable charge/effect/trap data required by the query contract. Keep neutral -1 distinct from an unknown/poison contribution0. Preserve contributions from provisional visits, not only final local facts. Resolve every stable reference uniquely against the current request's graph and verify call position/target/arity/ordinal before applying the original meet to freshly initialized target accumulators. Do not persist activation FN numbers, edge indexes, heap offsets or seal pointers as reusable identities.

A ResultCID match can stop downstream recomputation only when the downstream read footprint depends solely on that unchanged result. If it also reads a changed definition, type/effect/ABI or graph structure, it must re-evaluate those dependencies. Exact payload comparisons remain required during experiments; a digest match is not permission to ignore different poison, diagnostics or target updates. Store physical timings and reconstruction evidence in a separate receipt referring to both CIDs. A cache hit is replay evidence, not a receipt falsely claiming fresh evaluation.

Shared-store availability must not change accepted output bytes. Preserve the same activation-local memo and optimization setting while comparing shared-OFF, cold and warm states. Require exact CODE/container/export bytes and three-generation selfhost fixed points across those states. Deterministic logical admission/charge governs optimization selection; physical work saved by a hit must not silently admit more rewrites. If charge depends on mutable context, either seal that context in the request or define a versioned charge contract before reuse. Observable fuel and its order remain separate semantic obligations. Current authority, external effects, clock and randomness are excluded from the first shared query class.

Preregister the next implementation phases separately:

1. **Finish the local emitter candidate.** Independently review frozen source and certify the exact retained handle/descriptor/pool/load path, owner cleanup and refusal behavior; then separately register bounded native positive/refusal fixtures, original19 inputs, default-OFF bytes and selfhost gates. This stage adds no persistent identity or store. Count actual emitted rewrites, not analysis-compatible sites.
2. **Pure offline request/result encoding.** Implement a canonical encoder and complete read-footprint extractor in the project's language stack, with exact snapshot identities and ordered graph references. Freeze schemas and contracts first. Mutate each evaluator/query/context/bound/rule/ABI/trap/resource field and require the expected request distinction. Test identical semantic results under changed requests without dropping the new request/result correspondence. No compiler behavior change yet.
3. **Default-OFF checked CAS publisher/importer.** Initially accept only completed pure supported shape queries. Invalidate before partial writes; verify payload digest, stable-reference resolution and evaluator/result correspondence before publishing valid-last. Malformed, stale, unsupported, poisoned or partial entries become misses/refusals per the frozen contract. Hash integrity and semantic correspondence are distinct validations; unknown read sets deny sharing.
4. **Deterministic charge and byte reproducibility.** Freeze logical admission, imported charge and remaining-budget semantics. Exercise every refusal/publication prefix and stable-edge dependency change. Run shared-OFF/cold/warm with identical local settings and require exact output bytes, exports and selfhost generations. A result-value-only gate is insufficient. No automatic persistent-cache enablement.
5. **Measure the complete cost.** Compare local-only and shared variants with encoding, hashing, lookup, validation, graph resolution, replay and storage included. Keep compiler analysis cost separate from generated Embench runtime, use matched low-load conditions, and retain negative or noise-level results. CID computation is not free; no present runtime gain is attributed to CID without an ablation.

These are prospective implementation phases, not authoring/native/publication permissions. The fixed typed seven-case memo evidence supports positive, zero and actual self-neutral replay within that fixture; it does not qualify a global store or a universal compiler theorem. No frozen emitter source, product source or runtime has been changed by this alignment note.
