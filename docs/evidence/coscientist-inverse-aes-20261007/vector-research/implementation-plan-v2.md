# Typed implementation plan v2 — lifetime-aware constant-index branch elimination

This supersedes the prospective rewrite/cost in the initial hypothesis, preserved unchanged in team-general-vector-witness-hypothesis. It is authoring guidance only: no implementation, compile, guest, solver, transfer or timing is authorized. Initial version retains **the exact original CMP** and removes only its certified B.LO/UDF pair. Savings: two static words and one successful-path instruction per admitted read. NZCV remains original; later CMP deletion needs a separate emitted flag-liveness certificate and prospective revision. The157 five-body SIR opportunities remain an upper ceiling, not admissions. Require32 actual emitted sites across at least3 priority bodies before performance experimentation; smaller scope is a negative applicability result, never a reason to weaken soundness.

## 1. Actual lifetime boundary and summary meanings

Facts name `(value identity, lifetime epoch, conditional length lower bound)`, not an immutable numeric handle. `h` can be reused after arena_leave/reset: handle100→leave→same handle1 passes the original handle check but invalidates length100. Explicit RT224/232, reset, region/scope transitions, capability/indirect/unknown calls and any unproved implicit entry/exit effect kill ALL vector shape/identity facts. Epoch increments are symbolic kill events, not a new runtime epoch counter. No facts survive across separate host guest invocations; TH39cdb resets context before each. A new function parameter token describes its own invocation and lifetime, never a globally stable allocation identity.

Independently pinned allocator review confirms normal returned vector allocation descriptors have exact requested N; failed allocation may modify cursors/items before trapping. The proof applies only to the original normal continuation. Preserve original handle validation/failure priority at every read; no validation or allocation is hoisted. All partial arena/fuel effects remain original. A fact invalidated by epoch reset cannot be revived from numeric handle equality.

`assoc_in_place` RT208 returns SAME input handle/length and changes an item: shape may survive, item contents never cached. Ordinary assoc RT184 returns NEW same-length handle; not alias. Conj160 and drop192 return NEW different-length handles. Initially refuse184/160/192 instead of conflating them with208. Different allocation origins across invocations can contribute the minimum conditional length at a private parameter; within each CFG, identity and epoch must be exact or facts meet to unknown.

Transitive known calls need not be killed indiscriminately. Effect summary `lifetimeClean` means complete checked SIR plus all reachable direct callees plus actual emitter entry/exit/auxiliary paths and runtime implementations contain no descriptor rewind/reset/callback. Shape transfer and return alias are separate fields. gn-op-fn2(944) / gn-epilogue(974) currently emit register/frame and optional fuel operations, with no arena enter/leave; seed lowerer has no hidden arena operation. This is a **current source observation**, not a future automatic assumption: fingerprint those helpers/runtime contract and bind actual FN prologue/return machine coverage before native qualification. Any future hidden arena/scope-leave invalidates lifetimeClean even if SIR has no224/232. A returning callee that can rewind an old caller vector kills caller facts, even when its returned vector has a valid new descriptor.

Parent's exact19 source census has zero OP-CAP/CALLI and zero RT224/232. Priority RT sets: EDN/SHA/Pico176/208/200; QR also72/144, XGB144. String helpers72/144 require independent lifetimeClean runtime implementation proof; unknown means caller facts killed. This feasibility observation does not certify summaries. FNcounts26/32/86/82/20 mean the64 bound must be SCC size, not a64-function module cap.

## 2. Bounded table layout in existing G, no new heap allocation

Prototype tables use **unused tails of the existing four4096-word G banks**, not extra mem-alloc, runtime vectors, heap/table headers, MM counters or a new G size. Existing source G bases: gn-a-sreg16, gn-a-use4112, gn-a-dk8208, gn-a-dv12304; normal resets use ns/dp prefixes. Reserve tails only after a complete module precheck proves actual `gn-need-s`, `gn-need-t`, parameter arity and descriptor/home accesses bounded<=128 for EVERY function. Scratch begins+256, leaving a safety gap. If any function exceeds the bound, disable this analysis for the whole module before writing scratch. The initial scratch certificate must independently inspect all source/emitter paths for bulk bank clears/read dependencies, not just FF-NSLOTS/DEPTH.

On module initialization, read-check all reserved words are zero BEFORE writing. Nonzero scratch (including reused compiler M) disables analysis without mutation; don't assume mem-alloc cleared it. This avoids a snapshot allocation or restoring unknown old values. Zero scratch on every normal/error/analysis-budget exit after activation; do not mask/change an existing MMERR. Dedicated error cleanup is mandatory before gn-run-open returns. Unsupported ordinary modules retain original G allocation and emission. Exact same-M repeated/open/failed-state controls remain future required gates, not existing qualification. Rooted analyzer writes only these reserved zero words; no code/FIX/label/FF/counter write before certificate completion. A complete independent indexed-read/domain proof must precede use of this layout; this design does not itself prove G-tail safety.

## 3. Typed SIR/NF summaries and root propagation

Read IF op,a,b,c from existing fixed-width SIR; OP-FN1/END2 own each body, LABEL9 and BR10/BRZ11/BRNZ12 define CFG. OP-LGET4/LSET5 define slot value identities, CONST3 full i64 constants; RT14 identifies176read/208write/200alloc; CALL13 is direct target/arg base/count. Types come from checked NF chains/FF fields, never source spelling. Validate FN ids/body span/end ownership/labels/parameter chains/type/pool bounds before every indexed read. FN0/public/exported/FADDR/open/replacement/unknown indirect entries cannot acquire a positive parameter bound. Public entries themselves remain generic; they may seed known allocation flows to private callees on actual normal continuations.

Build complete direct-call/FADDR graph from ALL original module rows, including exported observation/bounds paths and dead/probe rows conservatively. Each private parameter bound is the minimum across ALL incoming arguments and reachable root paths. An unknown caller supplies unknown, never omitted. Replacing functions or missing callers invalidates admission. Track vector allocation200's normal-return conditional shape only when requested constant is nonnegative/bounded; conditional size branches meet by min. Preserve handle origin tokens within the caller. Record normal-return alias separately from return-length; all reachable returns must preserve exactly the parameter token in the current lifetime to certify alias.

For recursive SCCs, do not initialize a self-call to 'alias' or a positive parameter length. Require an externally reachable entry seed plus checked simultaneous invariant: each recursive argument preserves the relevant parameter/lifetime/bound, all base normal returns preserve the declared alias, and no lifetime effect in the closure. Mixed origins are allowed at different entry invocations; within each invocation only the parameter token survives. If these structural obligations are unresolved after eight complete passes, SCC returns remain unknown; no acceptance of a capped partial approximation. A SCC with no witnessed base/alias return is refused initially. Effects can be computed conservatively over cycles independently of return/length summaries.

## 4. Per-function CFG meet and emission consumption

Start with certified parameter facts, otherwise unknown. A normal allocation creates a new SIR-origin/epoch token; copies preserve it; LSET and actual coalesced producer writes create/kill exact definitions. Preserve facts through total scalar constants/operations and exact known lifetimeClean calls using their return transfer. Kill at every explicit or implicit reset and unknown call. In-place writes preserve shape and read fresh items, but do not confer a validity or value memoization certificate.

At joins require same value token+epoch on every predecessor; L=min of their known bounds, else unknown. Unsupported predecessors invalidate, not disappear. Initial loops conservatively retain a parameter/unchanged local only if every backedge preserves the exact token/epoch; scalar induction intervals remain unsupported. Different vector assignment along any loop path invalidates. Budget exhaustion makes the function's site certificates all zero before emission. This constant stage is a foundation for later bounded loop intervals; it does not silently implement them.

Read admission requires vector-i64/i64 types, literal full-width k with0<=k<L, supported original generator path, matching actual source descriptor at this SIR and lifetime-clean prologue/call/return mapping. Preserve generic handle check, descriptor LDP/loads, original CMP and fresh items LDR. For initial emission support only ordinary inline low-temp mode0 `gn-rt-at`→gn-hchk→gn-vidx; existing cache/high-temp/private/fused modes fallback until exact mode-specific branch offsets and certificates are added prospectively. This limitation may fail32sites/3bodies; report it honestly rather than adding modes without review. Each site record must distinguish potential semantic range proof from actual accepted generation mode.

At gn-vidx emit its original LDP and CMP, omit only B.LO+2/UDF0, then original items pointer and offset/index calculation. No new branch/FIX/register/frame/store/fuel. CMP always establishes exactly the original NZCV on the admitted successful path, including earlier cache-EQ hazards in future extensions. Site consumption checks source i, current t, descriptor identity/k, non-error M and current module certificate; otherwise emit exact old path. Every other code word/edge/literal relocation is projected canonically. Reject any certificate introduced after code emission or from previous function/epoch/compilation.
