# Isolated M105 variant timing on Apple M4

`analysis.json` is regenerated by `analyze-variant-timing.py`. The analyzer
checks each campaign's 19 Kotoba and 19 C selected raw samples against its
report and requires every selected CPU-gated attempt to be accepted.

The `raw/` archives contain the campaign report, selected and rejected raw
attempts, quiet-host CPU readings, the runner scripts, and upstream benchmark
logs. Campaigns use the common C build receipt recorded in
`../../m105-abba-m4-20261016/analysis.json`.

The control-adjusted comparison is descriptive. Each compiler variant has two
campaigns, and the workloads with byte-identical images are used to estimate
the run-period shift before interpreting the changed-image ratios.
