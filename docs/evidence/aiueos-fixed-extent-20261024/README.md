without an adjacent length argument only when every caller passes a rooted
region with one identical literal extent. Unchanged self-call arguments can
carry that contract; they cannot seed it. A self tail-call's parameter stores
are accepted only when their last writer is a direct read of that exact same
parameter. Computed, loaded, swapped or changed values are not identity copies.

closed project has a bounded24-level walk. IRQ arguments never become roots.
