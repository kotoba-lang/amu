# A writable Mac context for Amu-generated code

`seed/macos-context-main-packager.kotoba` adds a 16 KiB writable `__DATA`
segment to the variable-length arm64 Mach-O diagnostic. Its PIE-relative
wrapper passes that segment in `x7`, writes fuel 1000 at ABI-v11 context
offset 8, the generated code address at 384, and the code length at 392. It
reads the address and length back before calling the generated entry and
traps if either differs. The remaining context function slots are zero:
there is **no Darwin capability runtime** in this image.

The pinned Amu-built ARM Linux compiler emitted this Kotoba packager from
source SHA-256
`b936417af61efe8dfe13b657766408d7bb6d0776ad99e6834a9be2c5888f2edb`;
the packager ELF SHA-256 is
`4e4943db070b55da2669889366c22cd5eb1d1d615c2f42a76f3175d9d1751d4a`.
The source root is
`285c54f826d5f7f77db6827bc21c622c2c777cea252a1ba4816d8b01351807e1`.
Both Kotoba compilation and packaging still ran in a local Podman Linux VM.

On Apple Silicon macOS 26.4, the packager's 136-byte Amu-generated loop ran
from a strictly verified ad-hoc signed copy and exited 42 with no output.
The unsigned image is 32,768 bytes: 16 KiB executable `__TEXT`
followed by 16 KiB writable `__DATA`, then an empty `__LINKEDIT` start.
The independent observer checked every command, context wrapper word,
generated byte and zero-filled data byte. Three strictly signed controls
trapped with SIGTRAP -5 and no output: fuel changed from 1000 to 1, the
code-base store replaced with NOP, and the code-length store replaced with
NOP. This checks the runtime path for the context writes as well as their
static encoding.

The same packager placed the previously re-extracted 3,254,848-byte full
compiler `main` into a 3,276,800-byte image (`__TEXT` 3,260,416 bytes,
`__DATA` 16,384 bytes). Two emissions were byte-identical. A signed copy
passed `codesign --verify --strict`, but the full compiler image was **not
launched**: it requires populated runtime function slots, arenas and Darwin
capabilities. An 11-byte input and an input whose image would exceed the FS2
single-value limit each returned 2 without an image. The complete hashes,
controls and status are in [receipt.json](receipt.json).

`scripts/seed/check-macos-context-main-packager.py` is a Mac observer only.
It pins source and image hashes, verifies Mach-O layout and FS2 admissions,
signs copies, runs the bounded loop and trap controls, and only verifies the
signature of the full compiler image. Python does not build the Mac binary or
substitute for a Kotoba runtime. Mac native full-compiler execution,
F1=F2=F3 self-rebuild, Linux-free AIUEOS build and release qualification
remain open under JUN-417.

Reproduce with a fresh FS2 `/work` directory containing this source, the
136-byte `macos-loop-main.raw` and the previously pinned full compiler raw.
Compile the packager with the pinned root using `compile ... --target
aarch64-linux --format static`, then invoke it with output Mach-O and raw
paths. Admit each native command through `scripts/seed/native_build_queue.py`.
Run the observer with the artifact directory and a new result directory on an
Apple Silicon Mac. The full compiler raw input and F1 provenance are pinned
in `docs/evidence/macos-large-main-packager-20261025/`.
