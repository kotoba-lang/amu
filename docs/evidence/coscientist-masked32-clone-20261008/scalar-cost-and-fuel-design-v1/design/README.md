# Bounded next scalar DAG expansion design

Design only, default-OFF proposed; no compiler edits or native execution. This does not authorize a build. Initial generic scope is one closed typed scalar callee with a single entry OP-FUEL [0,0,0], no branch except unique entry label, simple existing di-bin arithmetic, and one terminal call to an independently certified pure low-bit mask callee followed by RET/END. Nested depth1 only, <=32 SIR rows, <=7 locals/depth, <=5 arguments. Unknown effects, exported/open/indirect callees, callbacks, recursion, branches, vector operations, invalid owner/label ingress or incomplete scans refuse. No name-based admission.

Do not simply add OP-FUEL/CALL to di-body. Current di-init sets leaf1, while actual clone fuel is ordinary nonleaf: LDR x16,[x7,CTX-FUEL]; SUBS x16,x16,1; B.HS success; BRK0; STR x16,[x7,CTX-FUEL]. Its publication occurs before scalar arithmetic and before the nested mask call. A replacement must emit that exact source transaction with freg0 BEFORE changing emitter mode for inline arithmetic. It must not substitute private leaf x8 fuel or omit a zero-valued OP-FUEL operand. Underflow leaves the prior published fuel unchanged; the branch skips BRK only for sufficient unsigned fuel. Non-resuming trap is a scoped host contract, not proven for arbitrary hosts. CTX must be actual x7 from original gn-ctx at the call edge; preserve argument evaluation order, which already occurred before the call, and the source-defined call-entry fuel ordering.

Retain gn-save/gn-args/gn-ctx and di-save bank0/bank1 structure where qualified. Emit the entry transaction after argument setup, before di-init, using an explicitly audited helper with the original nonleaf sequence; clone snapshots cannot accidentally inherit freg1. Then interpret certified scalar rows through existing emitters, with a separate nested scalar-mask expansion. Nested mask charged0 is the first scope: require exact absence of OP-FUEL and exact bitmask contract. A charged nested callee remains refusal until its distinct private fuel publication/trap transaction has its own proof. All temp/local indices mapped into the inline bank, no new label/FIX/body mutation; leading unique label can be skipped only when all legal ingress is the single callee call edge and no FADDR/export/address escape targets the interior. Return maps to x0, restore caller emitter state, clear descriptor witness and gn-take original temp/result alias. Original dead x1 count, inactive x10 and scalar scratch behavior must be qualified by live read footprints rather than assumed irrelevant.

Original emitted clone uses callee-saved x19 to hold its value and restores it; expansion must preserve live caller x19..28 and homes. Existing low-register di-init uses x1..7; x7 is context and not a mathematical local beyond6 unless explicitly restored. This is a concrete admission limitation: reject local allocation to x7 until exact context/liveness restoration is proved. Arithmetic and UBFM must preserve original final NZCV (original SUBS is the last flag producer), preserve result for all signed/full64 inputs, and preserve exact support/type/effect/trap semantics. No broad 'pure' label overrides these constraints.

Resource contract is separate from language fuel. Expansion can change emitted CODE size and physical compilation work. Use bounded prospective code-growth/site/scan limits, one deterministic admission decision, fail-first CODE/FIX/MMERR semantics and no valid publication after partial compiler error. Existing di-call propagates MMERR from partial emission; its fallback rolls back only counts/state after a successful over-size attempt. Do not infer full buffer rollback or identical original capacity refusals. Either explicitly adopt and test a new compiler resource contract for ON or implement original logical CODE admission; no hidden budget relaxation. Owned scratch banks and reset/cleanup sizes need exact write-closure before source authoring.

Finite preregistration stages: SOURCE exact reversals and scalar model; component state controls with all allowed resource differences declared, capacities0..required-span, dirtyMMERR, active caller temps and homes/aliases, ctx/freg states; emitted function comparisons including full64 inputs and fuel0/1/2/exact boundary, invalid current-context behavior limited to safe testable host interfaces, checked escape/unknown nested negative fixtures; then original19/95/285 correctness and independently reviewed full19 quiet paired runtime. Each executable driver needs explicit frozen source plus two specific SOURCE receipts and root finite GO; this design grants none. Current SR32f7 campaign remains unchanged.

Static opportunity only: removing successful clone frame/call transactions could remove a substantial fraction of its 19 nonarithmetic instructions, but five original entry-fuel instructions must remain and caller save/setup may remain. There is no numeric speed prediction. Full native state/control evidence is missing; prototype source-authoring admissibility remains HOLD until helper signatures, write closure, resource contract and finite executable controls are separately frozen/reviewed.
