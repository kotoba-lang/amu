# Owned-group memory adapter SOURCE: HOLD

The exact proposed metric is the sum of Darwin ri_phys_footprint for every member of the newly owned session/process group. Its4GiB ceiling is a soft sampled refusal threshold. Shared-page contributions are summed as reported per process, without deduplication; this may conservatively double-count. It does not establish a virtual-memory cap, private-byte bound or universal physical-memory peak. Arena caps stay unchanged.

The import-inert adapter only loads libproc when an explicit runtime API object is constructed. It lists one owned process group, using a four-PID buffer and refusing any count outside1..2. Apple libproc returns a PID count, not bytes. Group membership must stay identical across a sample and each member birth identity must remain consistent. Read failure, empty/extra inventory, PID reuse, member exit or a threshold violation refuse. No global process enumeration, fallback or guessed-zero memory exists. [Apple libproc source](https://github.com/apple-oss-distributions/xnu/blob/main/libsyscall/wrappers/libproc/libproc.c). Local SDK15.5 resource/libproc headers are pinned; the96-byte V0 ABI and offsets are checked only as pure SOURCE data.

The pinned loader forks one compiler child. It skips AS installation on Darwin and requests CPU soft1800/hard1801; that original loader contract remains explicit. The failed V2 wrapper hard1800 contract remains a distinct unsuccessful proposal. CPython's generic EINVAL message does not identify the original V2 failed setter. [Python3.14 implementation](https://github.com/python/cpython/blob/v3.14.0/Modules/resource.c).

The next gate is a separately reviewed bounded owned-group fixture driver, at most2 fixed Python child processes,8 read-only samples,10s wall/5s reap and64KiB capture per stream. No externally supplied PID/command, resource setter, compiler or loader is authorized by this SOURCE freeze. The adapter itself has not loaded libproc or queried a process. Current typed binding8 and artifact identity remain unqualified.
