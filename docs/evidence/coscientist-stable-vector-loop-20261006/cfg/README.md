# Read-only CFG origin feasibility

No optimizer, product or frozen implementation file was changed. Current v1 measurements showed no qualified gain in its four changed workloads. This package supplies a separate prospective design: require an already-framed baseline leaf (`gn-f-fb > 0`) and replace only the linear origin proof with a bounded all-predecessor origin proof. Workload/function names do not belong in admission.

The exact original19 typed SIR equals the pinned pre-clone observer SIR for every workload. Baseline function/register metadata and cache mode come from the qualified product observer. Across 98 shape-eligible functions, the full closed-body rule plus rooted CFG proof would admit seven functions in six workloads: the existing five and two new functions. The prospective already-framed guard retains only the two new functions:

| Workload, function (evidence label only) | Reads | Proof visits | Frame | Existing/new callee registers | Static added words |
|---|---:|---:|---|---|---:|
| qrduino, FN62 | 9 | 69 | 144 → 160 B | 1 → 4; cache x20/21/22 | 21 |
| xgboost, FN15 | 5 | 47 | 144 → 176 B | 2 → 5; cache x21/22/23 | 15 |

These are static estimates, not compiled successor artifacts, measured costs or causal explanations. The estimates preserve runtime flag guards at every read, add three explicitly owned/saved callee registers, and include changed save/restore grouping plus flag initialization. The literal-pool alignment can add another four bytes. No register from the actual original read input/index/output overlaps the proposed cache registers. A new compiler must still prove all shifted stack homes and returns, and repeat actual machine/CFG/fixup/private-ABI audits.

For xgboost RT327, temp0 is defined by `LGET temp0 local1` at313. Both paths through branch317 converge at label322: the fallthrough path changes temp1 at318 and jumps319; the alternate path changes temp1 at321. Instructions323..326 affect index temporaries, not temp0. Every backward predecessor path from RT327 therefore reaches the same root-vector local definition. qrduino also has joins and an exact chosen-local selftail write. The selftail writes are qrduino6761 and xgboost334; both inputs are proved all-predecessor reads of the same chosen local. The original parameter plus induction over all such local writes establishes unchanged root identity. Alias propagation to a different local remains excluded, so the existing same-vector-phi control stays refused.

The proposed algorithm is rooted at each handle use, not a general graph search:

1. Validate the whole finite function and build its exact local predecessor graph. Branches, conditional fallthrough, labels and returns must match source semantics. Reject malformed/duplicate/foreign labels and all calls, indirect calls, capabilities, allocation, writes and unknown runtime operations.
2. For each vector handle input and each write to the chosen vector local, walk backward from every predecessor with the fixed temporary number. A last definition is a proof leaf only when it is `LGET` of the chosen vector local. Any other definition or an entry path without a definition refuses the function.
3. Meet with logical AND across every predecessor. A cycle in the backward dependency graph with no intervening accepted definition refuses the function. No recursive assumption is treated as evidence. The emitted certificate lists proof nodes, exact predecessor edges and accepted definition leaves for independent checking.
4. Keep the existing runtime validation flag. This analysis proves stable handle identity, not that validation already happened. The original first-read handle validation stays at its original site after fuel charging. Every read retains unsigned bounds, trap and fresh load. No first-read motion or compile witness strengthening is proposed.

N is at most8192 body instructions, E at most2N and Q at mostN origin queries. CFG construction is O(N+E). Each fixed-temp query uses O(N+E) time and O(N) temporary state. The worst uncapped query cost is O(N²); a shared131072 visited-node budget bounds it and exhaustion refuses optimization. The replay implements an iterative postorder walk. Other existing compiler scanning costs remain separate and must not be misreported as constant time. A native implementation should use bounded arrays/worklists and make every malformed/cap/unknown result restore the original generic path.

Closed-body admission excludes every call edge that could mutate descriptors or clobber the cache registers. Origin alone is insufficient: constructor's independent forward oracle deliberately invalidates calls, while the narrow rooted origin query can still identify a local across them. Full effect admission rejects those functions. Conversely the independent oracle can propagate a same-vector alias local, while this minimal extension conservatively refuses it. The two analyses have different scope, documented in design-receipt.json; no mismatch is silently called agreement.

Eleven abstract controls pass: actual scalar diamond, both arms reading the same root, alternate local, constant/redefined temp, missing definition path, cyclic dependency, exhausted budget, returning-call effect and scalar input to a root-local write. The controls mutate diagnostic SIR only and do not claim typed/native executables. One initial cycle fixture used an unconditional branch that could no longer reach the target, so acceptance was correct; it was changed to a conditional backedge that also reaches the read. The failed draft is retained. An initial root-local-write mutant copied the unchanged original operand by mistake; it was corrected to the scalar temporary. Portable replay initially compared Python tuples to JSON lists; normalizing serialization fixed the harness without changing analysis results.

Run `python3 replay.py` from this directory to reproduce all original19 analysis from the owned pinned JSON inputs. Run `python3 controls.py` in the original workspace for the real-source mutation controls. analysis.json holds all admission/refusal facts and original external input pins. design-receipt.json holds actual join/selftail certificates, register checks and independent oracle comparisons. These files make no timing, time-share, C-or-better or product-promotion claim.
