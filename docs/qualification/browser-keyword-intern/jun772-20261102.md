# Browser keyword intern candidate — JUN-772

2026-11-02, source based on Amu `d4d6841f129d846db13393a469645e1ca91fb568`.
This is local candidate evidence, not a released compiler or an end-user app.

The browser runtime now includes seed/73's private keyword intern rows and
initializes them before guest entry. They are internal runtime state, not an
external operation; each Worker starts with its own table. The arena is bounded
at 262144 rows and reserves 6 MiB. Wasm and generated JS share this runtime.

The baseline macOS ARM64 full root SHA-256 was
`f5d36c21efff28c8fdc1125832c99607ee0f09d0ec1db1290213d72f77d43b5b`.
Building candidate FULL-MANIFEST with the native root and native packager gave
F1 and F2 compiler containers with identical SHA-256
`fb6effa9f53560008260d124a5f1964c4986d58ecfe4bd1305196ed0f70ac7a7`.
The candidate F1 signed image SHA-256 was
`909d6280070b2609702eb42380f37cfd7fc5b97027898de7f8c228dccc6113ba`.
The tests below were run on macOS ARM64 with Chrome 156.0.8078.74.

- `scripts/seed/check-browser-keyword-intern.py` observed the unmodified root
  refuse the guest on both browser targets with E7101. The candidate compiled
  both, returned 0 for literal/dynamic/Unicode/document/arena-scope cases and
  1 for an intentionally incorrect expected keyword name. Wasm and JS reports
  including remaining fuel matched. The same guest returned 0 with `bin/amu`.
- The existing `scripts/seed/check-js-browser.py` passed 24 runtime cases,
  four probes and 11 float refusals, with Wasm/JS parity.
- The Bunsho editor source with its exports narrowed to `main` compiled to
  Wasm and JS; the Wasm `main` returned 13 in Chrome. Its definitions were
  otherwise unchanged. This is the editor's test aggregator, not its
  document-valued UI exports, persistence or a runnable product UI.

Reproduce the focused check with the candidate and baseline root images:

```sh
python3 scripts/seed/check-browser-keyword-intern.py --compiler /path/to/candidate-F \
  --baseline /path/to/baseline-F --output /new/output --browser /path/to/Chrome
```

The private table's full-capacity exhaustion, independent browser security
review, full native/selfhost tiers, CI, UI ABI, QEMU, persistence and release
qualification remain open. The local evidence must not be used to claim those
items passed.
