# 課金を残した64ビット符号なし比較の置換（2026-10-07）

型と本体を完全照合した私有関数2つを、64ビットの比較命令へ置き換える実験用Kotoba実装を作った。元の入口での燃料消費1回を残す。Amuによる4世代の自己再ビルド、元19入力の生成、独立したソース・命令列検査、120組・240回の有限実行確認を通した。性能と製品採用はまだ認定していない。

## 規則と前提

対象の意味は、符号ビットを反転して符号付き比較を行い、その否定を返すこと。

```text
not(signed_lt(x xor 2^63, y xor 2^63)) → unsigned_ge(x, y)
```

元の親関数は燃料1回、子関数は0回。双方が私有・非公開で、2引数・2スロット・i64引数・bool結果、指定した完全なSIR本体、閉じた参照、関数アドレスの使用なしを満たす場合だけ適用する。関数名やベンチマーク名では選ばない。

引数は互いに異なる安全なレジスタか検査済みのローカル配置に限定し、課金前にx0/x1へ取り込む。下位の生存値を保存し、元と同じ5命令の課金の後にCMP64/CSET.HSを生成する。同じ物理レジスタの引数など、前提が成立しない場合は従来の呼び出しへ戻る。共有の4,096ワード・64箇所の上限と24ワードの予約を守り、実際の置換は11または12ワードだった。

値の法則は `signed(x xor 2^63) = unsigned(x) - 2^63` から全64ビットについて導く。81組の境界値と、符号付き比較・32ビット比較・引数上書きの反例も保存した。今回の環境では既存のSMT実行環境が見つからず、インポート失敗を保存した。SMT問い合わせは0回で、機械検証済みの定理とは呼ばない。

## 実装と検証

- ソース：`5e545aaf…`。新機能は実験用の既定で無効。
- 4世代のコンパイラ：886,504 B、`3ad29932…` でバイト一致。
- 無効時は元19入力すべてが前候補と一致。有効時も他18入力は一致し、Aha-mont64だけ変更。
- Ahaの2箇所で元の課金と64ビット比較を確認。周囲の984ワード・106辺・リテラル領域を投影比較し、3つの固定命令改変を検出した。元の汎用関数も保持。
- 診断付き生成器は通常生成器と追加fixtureのKSEED全体がバイト一致。普通の引数、計算済み引数、下位の生存レジスタ、下位の生存ローカルの4配置を受理し、同一レジスタの配置を拒否。
- C診断ローダー10本で120組・240回を実行。40組の期待する停止、80組の正常終了で、64ビット引数、値、燃料、報告される資源使用量が一致。最初の6回と残り234回を分け、先の実行は繰り返さなかった。

燃料0・1の停止と、燃料2で正常終了して残量0になるケースを、実際の終了状態・報告・値で区別した。大きな燃料値は診断用ローダーの上書きで確認した範囲で、製品が同じ予算を受理する保証ではない。

独立担当は全240回と生成物を再検査した。親担当も[3ファイルだけの保存証拠](evidence/coscientist-inverse-aes-20261007/charged-compare/README.md)を別ディレクトリで再検査し、元ディレクトリ・ソルバー・ネットワーク・ネイティブ再実行なしで照合できた。最初のソース作成時のガード不足はビルド前に修正し、元の草稿を保存した。オフライン検査器の読み取り失敗も別に保持し、ソースや期待値の変更として隠していない。

この検証は有限入力の正常な生成結果と、報告される終了状態を対象とする。ABI全体、非同期の途中観測、未報告の全メモリ、容量不足・生成後半の拒否・巻き戻しを含むコンパイラM全体を保証しない。製品全体のセルフホスト完了も意味しない。

同じM4で実行器1本を作り、元のAha-mont64を0・1・32回の入力で基準・候補・Cへ与えた9回の確認は通過した。結果は0・1・1、ネイティブの燃料は1・850・27,138、Cは0で一致。速度は独立した低負荷測定で判断する。公式Embenchスコアではなく、元C成果物のコンパイラと全フラグは不明のまま扱う。

Aha単独の改善やC超えが得られても、全19入力でC以上という目標の達成にはしない。複数の入力に効く一般的な制御フロー・ベクトル境界の解析も、同じ意味保存条件を明記して調べる。
