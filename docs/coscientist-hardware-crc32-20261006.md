# CRC32 最適化の検証結果（2026-10-06）

IEEE CRC32 の完全な表と再帰形、呼び出し元の u32 条件、元の fuel 課金を確認して、AArch64 CRC32B 命令へ置換する試作を検証した。候補 `ed0d49bb` は CRC32 の既存版 `761856bb` 比で **2.1547倍**となり、事前登録した改善条件に合格した。他18本はネイティブ画像が同一で中立、性能退行はない。

元の19本すべてを同じ Apple M4、固定した C、同じ runner と条件で新しく測定した。**570受理組 / 648試行組 / 78棄却組 / 1,944生サンプル**を保存し、全19本が安定性条件を満たした。全19本の実行時間の幾何平均は **4.0988%減**、候補/C 時間比は **7.3833倍**（既存版/C は7.6989倍）。この全体値は記述統計であり、別に有意な全体改善を証明したものではない。過去の測定値や別の波の値は混ぜていない。

CRC32 の平均は既存版 3,417.878 ±64.111、候補 1,586.240 ±145.203、C 1,706.400 ±0.613 ns/body（±は標本標準偏差）。Cとの差120.160 nsは標準偏差の和145.817 nsを超えないため、**C超えは合格していない**。全19本のC超えも未達で、**公式Embenchスコアではない**。

測定条件は各本30受理組、最大90試行、baseline→candidate→C の回転順、最低区間50ms・目標300ms、ホスト負荷≤4、推定背景idle≥90%、各腕の相対標準偏差≤0.1。改善・退行・C超えの合格には1.05倍以上と平均差が両腕の標準偏差の和を超えることが必要。
