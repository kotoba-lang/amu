## Identity and experiment

The current checked definition identity is content addressing of normalized typed
implementation, effects/interface/profile and dependencies. Computation identity
would additionally seal canonical input values and explicit handler/state identity.
A recipe hash does not make mutable handles immutable or remove observable fuel,

## Runtime correction and next experiment

The preceding registered hypothesis said in-place vector append changes an existing
descriptor length. Inspection of `tools/kexe_loader.c` corrects that assumption:
`intern_vector` increments vector_used and initializes a new descriptor;
`checked_vector_conj` returns that new handle. Old/new handles can have different
lengths. In-place association changes item data. The old archived hypothesis is
retained as historical evidence; this is its explicit correction. This candidate
still crosses no mutating runtime operation and reloads the descriptor.

The [next registered hypothesis](evidence/coscientist-vector-validity-20261006/next-hypothesis.json)
is guarded loop-region descriptor/data-base reuse for ordinary vector reads,
with actual SIR admission census first. Keep original per-access index/fuel/trap
boundaries and fallback on failed entry guards. Unknown effects, mutable handle
provenance and unproved control flow refuse. It is not implemented or measured.
