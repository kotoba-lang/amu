# AES 最適化の検証結果（2026-10-07）

完全な AES 表・型・呼び出し構造を確認し、AArch64 AESE/AESMC 命令へ置き換える試作を検証した。元の fuel 課金と公開順序を保ち、開いた関数値・対象外の呼び出し・feature 無効時は元の経路を使う。候補 `8e35a8e1` はソースから4世代でバイト一致。元19本のうち AES の4箇所だけが変わり、他18本の画像は同一。

同じ Apple M4 で既存版・候補・固定したCを新しく測った。570受理組、679試行組、109棄却組、2,037生サンプルを保存し、全19本が安定性条件を満たした。AES は **1.2961倍**の改善に合格し、他18本には合格基準を超える変化・退行がなかった。AES の時間は既存版21,525.039 ±242.312、候補16,607.029 ±226.331、C1,430.714 ±24.078 ns/body（±は標本標準偏差）。候補はまだCの **11.6075倍**の時間がかかる。

全19本の時間の幾何平均は記述統計で **1.2793%減**、候補/Cは **7.5944倍**。過去の統計を混ぜていない。C以上のgoalは未達。**公式Embenchスコアでも製品採用済みの結果でもない。**

条件は各本30受理組・最大90試行、3腕の回転順、最低区間50ms・目標300ms、ホスト負荷≤4、推定背景idle≥90%、相対標準偏差≤0.1。改善・退行・C以上には1.05倍以上と平均差が標準偏差の和を超えることを要求した。

独立した3ファイル再検証は選択11,302ファイルのハッシュ・機械語投影・保存された生出力を照合した。初版の依存不足と、formalログ末尾の古いpin1件を保持し、最終2703件のpinを権威とする。期待値や元の実行を変更していない。

CPU機能は測定M4で起動前に確認した外部attestationに依存する。自動的な成果物feature admissionと製品統合はまだない。採用済みは `44bfaa28c` / `761856bb` のまま。DefCIDと最適化・ISAを含む生成recipeの識別は分ける。
