# Calibrated dynamic terminal-path census before descriptor-transfer design

The two preceding local descriptor candidates are excluded after negative original-
body evidence. This turn implements a separate diagnostic and obtains **dynamic
counts**, while retaining the qualified small-tail-frame product unchanged. This
is progress toward the full19 C-or-better goal, not a speedup or official Embench
score. No private descriptor-transfer optimizer is implemented yet.

## Actual original statemate path

The qualified selfhost native seed builds a diagnostic compiler, which compiles
unchanged pinned statemate source. The diagnostic extends only its separate loader
context with a counter pointer at offset400; all original context offsets remain.
No product loader, compiler source, default rung, bin entry or capability grant is
modified. Counters preserve x14..17, NZCV and the temporary stack balance, and add
no fuel charge. Ordinary result/fuel/resource/partial-item reports agree with the
qualified product and its original supervisor at all30 tested conditions.

Equal handles on sampled inputs do not establish descriptor validity for all inputs.

## Independent calibration and machine audit

Five independent programs/inputs predict3 entries,3 reads,1 terminal transfer,
2 reads matching their function-entry handle, and1 terminal argument matching it;
write counts differ with the negative-value branch. Ten additional input/control
cases allocate and use a different vector before a read or terminal transfer.
The corresponding equality counters correctly become false. Expected values,
partial items and original fuel match independently compiled product code.
Together with30 original conditions, this is45 comparison groups and120 supervisor
executions. Insufficient original fuel is included at1,2,64,805,806, alongside the
normal16777216 budget, for each0,1,2,17,32-body input.

Clang's independent assembler supplies expected save/restore encodings. The
actual diagnostic statemate contains1,689 balanced wrappers matching those words.
Every instrumentation conditional branch rejoins before flags/register restoration;
none introduces a returning call or return inside a wrapper. Counter offsets beyond
scaled immediate range use explicit addressed loads/stores and actual-length branch
patches. These instrumentation checks plus sampled parity qualify the observation;
they do not qualify a new production optimizer or arbitrary stack-limit behavior.

Independent calibration caught an initial observer mistake: generator state14 is
already the scalar-tree consumption flag. That observer skipped function1; earlier
statemate counts are excluded despite their narrow state checks passing. Corrected
ownership uses verified unused reset cell15, followed by fresh calibration and
original observation. The unsupported initial calibration vector constructor and
fixed conditional skips are also retained as authoring corrections. Production
code was unaffected and no failed expectation was weakened.

## Next registered implementation contract

Investigate a **public cold entry and sealed private terminal entry** for validated
vector descriptor transfer. Only actual closed mode2 Vec functions with NP1,
NS/DP<=3, zero frame/spills/outgoing/returning/unknown calls and no allocation can
qualify. Spare x3/x4/x5 would hold length/item base/positive validated key. Every
actual read/write must dynamically require a nonzero matching handle; misses keep
the original handle/index checks, hits retain each access's own bounds check.
Original five-word published fuel remains at every charge before the same access.

A private edge must prove target classification from exact typed SIR and original
prescan, owned labels, real slot/depth bounds, closed metadata and an actual
unexpanded terminal call. Public exports, function addresses, imports and unknown
callees remain cold. Layout must validate the actual private-entry marker; generator,
layout and internal ABI must be included in artifact recipe identity. Branches,
root replacement, partial fuel/traps, every allowed operation's scratch registers
and allocation/effect boundaries need proof beyond the observed equal handles.

Independent public/private/cold/changed/invalid/alias controls and entry/shape/type/
open/label mutations, existing508/14523 expectations, native fixed points, all19
semantic/code audits and fresh unchanged-rule paired product/candidate/C timing
remain prerequisites. Permanent fixtures, normal gates and committed-source
