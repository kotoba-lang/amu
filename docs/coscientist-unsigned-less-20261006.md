module-unique owned labels qualifies. The pattern contains no fuel, runtime,

The specialization is separate from prescan leaf classification. Original caller
frames, locals, depths, callee-saved registers and published fuel remain. Existing

## Corrected next census and prospective hypothesis

Direct OP-RT counting shows119 runtime accesses in391 small mode2 functions,
with no function having multiple direct runtime operations. That misses expanded
CALL writers and cannot reject a local cache by itself. Counting actual inline
put emissions adds383 writer accesses; **119 functions combine a direct runtime
access with an inline writer**. There are291 observed terminal B edges among
small mode2 functions. These counts prove neither eligibility nor dynamic cost.

The next [registered hypothesis](evidence/coscientist-unsigned-less-20261006/next-hypothesis.json)
therefore targets a **same-local read-to-inline-writer descriptor witness** in
proved spare registers. First validation stays at the original read; a following
exact closed same-handle writer may reuse length/data base while retaining its
original index check, fuel/trap/partial-state ordering. Local replacement,
branches, unknown calls/effects and open/changed writer shapes invalidate the
witness; uncertain register aliases retain the original path. No runtime
key branch or result memoization is assumed. It starts from the qualified
small-tail-frame product, excluding this rejected prototype. It is unimplemented
and unmeasured. Cross-terminal descriptor transfer is a later candidate requiring
a separately proved internal/public-entry ABI, not inferred from a local witness.
