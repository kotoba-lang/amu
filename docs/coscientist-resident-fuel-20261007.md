# 連続する燃料課金の重複処理削減（2026-10-07）

AES v2 の閉じた呼び出し形にある、連続6回の非leaf課金を対象にした。最初の元課金位置で unsigned fuel >= 6 を確認し、十分なら x16 に残した値を使う。元の6回の減算と6回の燃料公開をそれぞれ維持する。不足なら元の6つの LDR/SUBS/HS/BRK/STR ブロックへ進む。非ゼロmodeは以前の汎用呼び出しへ直接進む。引数評価、AESの値演算、公開される関数値、元の拒否条件は変えない。

候補のソース41は `e94ab4df`、ネイティブは `a236b3e8`（871,760 B / offset 0）。ソースから4世代のバイト一致を確認した。既定の新featureは無効で、元19本の生成画像がAES v2と一致する。明示的に有効にした試作はAESの4箇所だけを変更し、他18本の画像は同一。49語の各箇所が65語へ増え、十分な燃料があるときの課金部分は30命令から16命令へ減る。これは静的な命令数であり、速度改善を証明する数字ではない。

実装は単なるpureラベルから燃料所有権を推論しない。固定した埋め込みローダーの `fuel-exclusive-writer-v1` と、コードに束ねた要求mask6（AES + scoped fuel ownership）を前提とする。閉じた完全な領域、隠れた呼び出し・燃料書き込みなし、scratchの所有、元の公開値と不足経路を別途照合する。一般のcontext ABI v11やraw sidecarに所有権があるという主張ではない。DefCIDと生成recipe/host requirementsの識別は分ける。

G1の共有ビルドhelperが未使用の初期binaryも作り、初期のCビルド数上限を超えた。未使用版をすべて保持し、手続き上の偏差と追加予算を記録した。実行数76、ソース、期待値は変えていない。課金トレースの最初の不足経路LDRを消す対照は、既に同じ値がx16にあるため挙動が変わらなかった。これを候補の失敗や検出成功として扱わず、記録を残してBRK破損の対照を事前登録した。正例50件は再実行していない。符号付きguard対照は経路選択の違いであり、同じ値が返るケースを意味保存の失敗とは呼ばない。

診断ローダーの引数・燃料の初期化はfork前だけに加えた。fuel0や高いu64値の試験は通常の製品予算許可を意味しない。ログは1つの共有page内の互いに重ならないcontext/log領域を使い、実公開値を読み、registerとflagsを保存する。トレースはコピーした実課金prefixの有限検証であり、全ゲストの検証や汎用ABIの健全性とは分ける。

測定器は別のversioned host contractとして準備している。元の測定ループ、contextと各call前のresetを維持し、最初に実CPU機能を検査する。コンパイラが作った既知の画像・入口と、Cの既知の内容・exportだけを受け付ける。Cは埋め込んだ既知bytesから私有の読み取り専用コピーを作って読むため、検査後の外部pathnameを直接実行しない。48個のraw入口対照と8個の小さなC対照を独立レビューした。初版のsourceコピー競合と、拒否文言の誤った検査を保持し、後者は同じ生結果の分類だけを直した。これは元のCベンチマークを実行した性能証拠ではない。

**全19本の測定と独立監査を完了した。AESだけの実験候補として改善を確認したが、全体改善・C以上・公式Embenchスコア・製品採用は未成立。** AES v2 `8e35a8e1`、候補 `a236b3e8`、固定した元Cを、zebulunのM4上で各本同じ測定器を使って比較した。過去の時間統計は混ぜていない。元19本×3経路の57件の実ホスト事前検査を通し、入力ハッシュと実行契約を照合してから、一度だけ登録済みの全19本キャンペーンを実行した。

AESはbaseline/candidateで1.095870倍、時間が8.7483%短い。事前登録した1.05倍以上と差が標準偏差の和を超える条件を満たした。それでも候補はCの9.9885倍の時間を要する。他18本の生成画像は同一で、測定差は判定上すべて中立だった。全19本の記述的な幾何平均baseline/candidateは0.999878（候補が0.0122%遅い）で、全体の速度向上とは扱わない。候補/Cの幾何平均は7.249833。これは実行経路を揃えた元bodyの時間比較であり、公式Embenchスコアではない。引き継いだC画像の内容は固定したが、元のコンパイラ版・全flagsは不明という限界を残す。

687組の試行から570組を採用し、117組を棄却した。試行の全2,061腕と145件の校正結果を保持した。全19本が登録した安定性条件を満たし、認定できる退行はなかった。集計時の浮動小数点丸め差とmanifest形式の読み違いは、生結果を変更せずオフラインで修正し、最初の失敗も保持した。再測定は行っていない。
