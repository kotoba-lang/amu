## How

- **`:document`** is its canonical EDN text (a `:string` at run time), the representation of stage-0's native backend and of the
  KIR route (KIR4/KIR5 doclib), so the three agree byte for byte. The operations are a **source library**: Kotoba text embedded in
  21-check (`ck-r6b-lib`, generated by `seed/tests/r6b/srclib/gen-srclib.py` from `r6b-lib.kotoba` + the KIR doclib) and appended
  to a module that spells one of its names. Type-directed heads (`get`, `assoc`, `nth`, `count`, `contains?`, `keys`) are
  rewritten to library calls after their first argument is checked as `:document`. Keyword text at run time comes from a
  per-module table (`__r6-kwtab`); a keyword whose text the module never spells traps rather than answer wrongly.
- **Library heads** `string-to-utf8`, `string-parse-i64`, `parse-long`, `ex-info`/`ex-message`/`ex-data` are the bodies of the
  reference's `intrinsic-helper-source` (kotoba-sema) and `lang/compat/clojure/core.kotoba`, renamed.
- **Capability names**: the friendly qualified call `(ns/op x)` of any catalogue entry is rewritten to `typed-cap-call`; the table
  is generated from `resources/kotoba/lang/capability-catalog.edn` (one authority; `--check` compares it with kotoba-lang's).
  Wires 20 and 23 are newly admitted; other unadmitted wires are refused by name (E2115).
- **Restrictions kept to stage-0's**: `str` items are `:string`/`:i64` only (stage-0 refuses `:keyword`/`:bool`); a `def` value
  that is not a literal stays E2124 unless it is a set/map literal of constant data, which is accepted only while unreferenced.

## Open (measured, ranked by modules blocked)

`#"re"`/`#(..)` (3 modules, 72 blocked; stage-0 refuses them too); `:f64` and `[:option :f64]` (kir.decimal 21, cbor 8);
untyped parameters (kotoba.bytes 18, posix-path 13, host-integer 9: stage-0 infers them); the result-typed interface of an
aborting import (kotoba.lang.json 12); `try` around a body the seed thinks cannot abort (compiler.schema, E2131); a map literal
as a constant `:document` (kexe-fs-forms); `:option-i64`; templates (clojure.set). A module that compiles is not yet a module
that RUNS as stage-0's does: the R6 per-module differential (design 1.4) is not run for the 33.
