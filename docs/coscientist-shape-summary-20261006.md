# Native closed-operation and normal-return identity summaries

The next co-scientist hypothesis after the [rejected closed-chain fuel candidate](coscientist-closed-chain-fuel-20261006.md) is constructor-established vector-length specialization. This step implements and independently checks its prerequisite summaries in Kotoba, compiled and executed by the qualified native selfhost. It changes no product code and removes no checks. **C-or-better remains unachieved; there is no new timing or official Embench score.**

The [Simple/GP2/worklist and proof framework](coscientist-rewrite-proof-20261006.md) is applied concretely: rooted instruction transfer rules, explicit reverse call dependencies, a bounded worklist, a separate global oracle, actual native fault injection, abstract SMT laws and an exhaustive finite dependency model. This is a diagnostic research implementation, not a general GP2 engine or an optimizer promoted to the product.

## Two separate facts

`closed(f)` admits only validated integer/local/control/fuel instructions, exact direct calls to closed functions, and the existing inlined vector-at, vector-assoc!, vector-count and pair projections. Allocation, capabilities, indirect calls, unknown operations and floating operations refuse the summary. Whole-body admission includes unreachable instructions. It is a **length-preserving admitted operation closure**, not a purity claim: element stores, fuel and traps still occur. The existing valid typed SIR and runtime value/header contracts are assumptions.

`identity(f)` means that **if the function returns normally, its result is its first parameter's original handle**. It additionally requires a typed Vec first parameter and Vec result, at most16 local/temp slots, and a CFG proof. Local copies preserve the handle fact; scalar operations/read/count results erase it; in-place update preserves its actual input handle. A direct callee's result preserves the first actual argument only when that callee has the identity summary. All incoming paths intersect facts; foreign/missing/duplicate labels and reachable END refuse identity. Both conditional branches are considered without assuming constant conditions.

The analysis uses separate F/Q/E/L vectors and never writes the compiler M/G. Intrusive queues deduplicate pending nodes. A summary can only fall from true to false; changes requeue reverse callers. Function and CFG work are bounded. Global failure prints all summaries false; a failed local CFG proof removes identity. This conservative refusal affects no generated instruction.

Recursive/SCC candidates are eliminated until stable. Acceptance asserts only normal-return partial correctness: any finite returning call execution has the same first-argument handle. It neither proves termination nor implies that a no-base recursive function will return. A bad return or disallowed operation propagates through its callers, including recursive callers. No benchmark/source name admits a summary.
