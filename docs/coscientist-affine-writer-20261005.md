# Affine signed vector-write fusion: two rejected performance hypotheses

Both candidates preserve the tested native observations, but neither meets the
prospectively fixed timing rule. No product source, launcher, rung or integrated
image changes. The qualified signed-clamp implementation at source commit
`33303be5a`, documented by `dbb707465`, remains the product baseline.

This follows the [content/computation identity investigation](coscientist-content-address-20261005.md).
Stable definition identities could support reusable specialization proofs, but
these experiments prove exact SIR and closed dependency bodies directly. They
are not DefCID caching or computation memoization. Benchmark bodies execute freshly.

## Hypotheses and implementation

Fresh native SIR inspection of unchanged canonical Picojpeg found a five-argument
helper computing wrapping `base + stride * k`, signed narrowing and a checked
in-place vector write. The original helper and writer each charge one fuel unit;
the narrowing helper does not. Recognition checks structure and closed bodies,
never benchmark/function names.

The first isolated Kotoba backend stages scalar arguments in x0/x1/x2/x3 and
fuses calls into MADD, SBFM and the original checked write. The second hypothesis
uses existing caller registers directly, loads absent operands into distinct
x0/x16/x17 scratch registers, and computes the index before loading the value.
It retains original nonleaf caller classification/frame, t<=2 admission and
explicit open-import refusal. This is a one-off compiler algorithm authoring
exception to mechanical AST refactoring, with no product edit promoted.

Original ordered fuel charges use a temporary remaining-fuel register. Successful
writes publish remaining fuel; bounds/handle traps preserve the original
pre-call supervisor state, and exhaustion publishes zero. Unknown shapes,
resource modes, temporary layouts and imported definitions retain calls.

The identity audit initially failed at the final fixture's nonexistent next
function offset. The repair bounds it by its own emitted instruction-word count,
excluding literal pools. Original failure and repaired script are archived;
compiler/guest bytes did not change. Actual signature-compatible allocating
import substitutions preserve baseline outcomes for open imports, while
intentionally closed controls differ or trap. Diagnostic allocator x7-clobber
loaders do not enter timing.

order, complete-triple acceptance and artifact pins from raw rows. Do not
relax thresholds or retry unchanged candidate bytes. These are custom aligned
body timings, not official Embench scores, a suite-wide geometric mean, or
C-level-or-better evidence.

Measurement began after native preflight while fuller supervisor proof was
running. Original metadata preserves that boundary and prohibits promotion.
Final state/import proofs completed independently. No integrated rebuild or
release gates are claimed for rejected variants.
