# AES直接レジスタ候補（2026-10-07）

閉じたAES計算の引数を実際のレジスタから読み、呼び出し規約への6回の移動と結果1回の移動を省くKotoba実装を作った。実行結果は有限範囲で確認済み。性能は未測定で、製品には採用していない。

6引数が既知の別々のレジスタに置かれたt0・t1の場合に適用する。その他は従来の経路に戻す。64ビットのmode・key、入力の捕捉順、下位の生きた値、燃料の6回の減算・公開を保つ。実装は通常無効で、実験設定で有効にする。

Amuが生成したコンパイラは4世代でバイト一致した。881,784 B、SHA-256 `4f2c1e1a48257c5116d9cf0ca503834923339d2eb06d2c8ed73640955f55ebe8`。元19入力では有効時にAESの4箇所だけが73→66語、計112 B減った。他18本は従来の復号候補とバイト一致。dr=0では19本すべてがその従来候補と一致する。ここで他の実験設定は有効のままである。

独立した生成命令の比較では、4箇所のレジスタ置換、周囲の2,970命令・439分岐、定数プールとオフセットを照合した。4種類の意図的な破損も検出した。診断用ソースで、実際にt0・t1が直接経路を使うこと、既存4経路が従来の生成方法を使うことを確認した。

実行証拠は3つの手順を合わせたもの。最初の手順は1組が成功した後、正の2^63を符号付き引数として渡してローダーに拒否された。ソース・期待値・イメージを保持し、同じビット列を負の表記に直した別手順で残りを確認した。次に元ローダーとの接続確認で、設定した燃料が正規上限2^53−1を超えたため、入口で拒否された。この記録も保持し、正規上限内の燃料7で4件だけを別手順で確認した。成功済みの試験は繰り返していない。

確認済みの実ゲストは566件。内訳は168組の値・燃料比較（336実行）、元19入力の99組（198実行）、x19〜28・SP・戻り先の28件、元ローダーとの64ビット結果比較4件。ローダーの起動は入口拒否3件を含め569回、ホストビルドは57回。単一版で全件PASSしたキャンペーンとは扱わない。正規の燃料7での接続確認は、燃料残量0で正常終了した。巨大なu64燃料値の診断は、診断用レポーターの契約に限られる。

[保存証拠と3ファイルだけの再検査手順](evidence/coscientist-inverse-aes-20261007/directreg/README.md)には、型付きソース・4世代・元19生成・生ログ・古い拒否・独立報告を含めた。[通常無効のソース差分](evidence/coscientist-inverse-aes-20261007/directreg/directreg-source.patch)も用意した。親担当は別ディレクトリで再検査し、566件の照合と拒否3件の区別を確認した。

この結果は有限入力の最終状態・燃料・報告される使用量と、正常に戻った場合のレジスタを対象とする。非同期の途中観測、ABI全体、未報告の全メモリ、コンパイラM全体・生成後半の拒否、製品全体のセルフホスト完了を保証しない。新しい性能測定やC超えの証拠にはしない。
