# Multiple-site cold fuel sharing: measured and rejected

The prospective >=2 syntactic charge-site condition was implemented and tested.
8 of19 workloads qualify for improvement; separated regressions are
edn. Reject global promotion under the predeclared no-regression
rule. Product source, fixture goldens, rung pins, bin/amu and integrated image
remain the qualified scalar-tree version.

## Hypothesis and implementation

Use the preceding exact cold-failure layout only when a function has at least
2 static charge sites. Prescan counts explicit SIR FUEL plus optional fuel of
exactly admitted inline wrappers. Unknown calls do not count. Private G field15
is reset each function. Single/zero-site functions retain legacy lowering.
No benchmark names, dynamic hints, body duplication, precharge or deferred fuel.
Static site counts do not measure dynamic calls or exclusive time. This is new
compiler algorithm authoring, not mechanical source refactoring.

Admitted functions retain each original decrement, context restoration/store,
leaf return/exhaustion publication and trap ordering. Shared failure blocks sit
before callable FF-CODE. Actual backward branch distance is calculated after
context restoration. Missing/out-of-range targets use original inline checks.

Native selfhost generations2/3/4 reproduce821,448 bytes, SHA-256
`e86550c03a4a77f737835bb9111bfaabe220596beb9a8176f619f717b5198796`,
with actual main offset0. Producer is the qualified824,952-byte scalar-tree seed.
All19 canonical workloads preserve results/exact fuel at0/1/2/17/32 bodies and
fuel1 exhaustion. All8,192 Pico workspace cells after1/2 bodies match.

Existing1,979 native executions pass across258 fixtures; native test/real
emitted layouts agree. Independent instruction audits resolve312 cold branches
in61 functions. Seven selected zero/single-site bodies (fr_write0, fr_write1,
id, sum, sx16, bin_ADD, r2_q0) match legacy bytes through END exactly.
All2,776 full supervisor reports and partial owned vector arenas agree for low
fuel, invalid writes/reads, division traps, context restore and charged wrappers.
Five supplementary zero-entry comparisons and8 signed-span/fallback generator
cases pass. Initial fuel0 is supervisor-refused; legal caller budget1 can reach
the callee guard at0. Native binaries and actual entry offsets are retained.

A supplementary audit initially looked up nonexistent `sx16_fuel`; the existing
fixture is `sx16`. Correcting only the audit lookup and resuming its existing
emitter outputs completed the proof. Backend and candidate bytes stayed the
same. The failed diagnostic and resume script are preserved.

## Address identity and next hypothesis

Current checked definition identity seals normalized typed KIR, profile,
desugaring contract, effect row, interfaces and dependency CIDs. It is content
addressing; a proposed computation address also seals immutable arguments and
explicit state/handlers. Such recipe identity is itself content addressing.
Native seed Kexe still records nil KIR/program, so these timings do not prove
DefCID caching. See [identity contract](coscientist-content-address-20261005.md).
Caching could improve incremental compilation or repeated computations, but
cached outputs cannot count as freshly executed Embench bodies.

The next registered hypothesis recognizes exact typed SIR for masked one-element
vector writers and their dependency, removing real call/return overhead while
retaining the callee leaf fuel transaction, bounds trap and partial publication.
Use the qualified product baseline; do not stack these unqualified cold layouts.
Unknown shapes/effects remain on legacy calls. Require full native proofs and
fresh quiet timings for all changed workloads. This next hypothesis is registered,
unimplemented and unqualified here.
